# Medibio - After-Sales Service Application

## 📋 Project Overview

This project focuses on creating an integrated application for After-Sales Service management, combining a mobile application and backend API.

The solution enables efficient management of technical interventions through:
- **Mobile Application**: Streamlines field operations, intervention handling, and billing processes

## 🚀 Features

- **Intervention Management**: Handle technical interventions efficiently in the field
- **Billing System**: Integrated billing and invoicing capabilities
- **Real-time Updates**: Synchronization with the central management system
- **User-friendly Interface**: Intuitive design for field technicians

## 🛠️ Technology Stack

### Frontend
- **Flutter SDK**: Cross-platform mobile app development

### Backend
- **NestJS**: Progressive Node.js framework


### Programming Languages
- **Dart**: Flutter mobile development
- **TypeScript**: Full-stack development

## 🔧 Installation & Setup

### Prerequisites
- Node.js (v14 or higher)
- Flutter SDK
- Git

### Backend Setup
```bash
cd backend
npm install
npm run start:dev
```

### Mobile App Setup
```bash
cd mobile-app
flutter pub get
flutter run
```
